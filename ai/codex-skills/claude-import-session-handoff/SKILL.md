Read `~/dotfiles/ai/skills/session-handoff/SKILL.md` completely before parking or transferring unfinished work. Continue-in-this-session and both Waiting statuses may retain claims while this same session will act again; parking/transfer requires a handoff before release. The handoff is a temporary Dibs task, deleted when consumed; durable lessons and decisions go to the plan or a knowledge record first, never only in the handoff.
