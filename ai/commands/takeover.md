Take over another Sessioneer session's unfinished work. Read `~/dotfiles/ai/skills/takeover/SKILL.md` completely and follow it.

This is the dead-session path: use it for a session that ended or died without a handoff. A parked, offered or handed-off session is `/rotate`'s path instead.

**Arguments:** `$ARGUMENTS` — `<agent> [profile] <session_id>`. The agent is the source agent. Omit the profile for the default account; only Claude accepts a profile.
